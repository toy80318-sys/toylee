# 평생든든 방문활동 사전준비 · 자동분석 프로그램

교보생명 **평생든든서비스** 방문활동에서 쓰는 고객 정보파악(Fact-Finding) 프로그램입니다.
회사 양식(앞면·뒷면)을 그대로 입력하면

1. 숨은보험금 · 할인 대상을 **자동 판정**하고
2. 고객께 그대로 읽어드릴 **안내 멘트와 제안 근거**를 만들고
3. 방문 **준비물을 자동 체크**하고
4. 고객별로 **누적 저장**하고
5. **엑셀 파일**로 뽑아 제출할 수 있게 해 줍니다.

쓰시는 곳에 따라 두 가지 판이 있습니다. **화면과 판정 기준은 완전히 같고**, 자료를 담는 곳만 다릅니다.

| | 태블릿용 | PC용(서버판) |
| --- | --- | --- |
| 실행 | `평생든든_태블릿용.html` 파일을 브라우저로 열기 | `시작.bat` 더블클릭 |
| 설치 | 필요 없음 | Node.js 한 번만 |
| 자료 보관 | 그 태블릿의 브라우저 안 | 그 PC의 `data/kyobo.db` 파일 |
| 엑셀 | 내려받기 | 내려받기 + 작성한 서식 올리기 |
| 여러 기기에서 함께 보기 | 안 됨 (백업 파일로 옮기기) | 같은 PC에 접속하면 가능 |

## 두 번째 프로그램 — 「기계약자 관리」 🐰

이미 계약하신 고객을 이어서 관리하는 프로그램입니다. 파일 하나로 돌아갑니다.

```bash
npm run build:new        # → 기계약자관리.html
```

- **탭 5개** — ① 고객정보 ② 사고보험금 청구내역 ③ 방문준비 · 상담메모 ④ 고객터치(알림) ⑤ 누적통계
- **보험명을 드롭다운에서 고르면** 그 상품의 약관 지급기준으로
  **특약별 보장영역 · 지급보험금이 자동 계산**됩니다.
- **알림** — 생일 · 기념일 · **보험 상령일**(보험나이가 오르는 날) · **특약별 보장 개시일**(면책 종료) · **감액 종료일** ·
  청약철회 기한 · 품질보증해지 기한 · 계약 해당일 · 납입 만료일 · 보장 만기일 · 후속조치 기한
- 자료는 **이 기기의 브라우저**에 쌓이고, 고객별 엑셀 · 누적 관리대장 · 백업 파일로 뽑을 수 있습니다.

## 태블릿에서 쓰기 — 파일 하나만

태블릿(갤럭시탭 등)에서는 설치도 서버도 필요 없습니다. **`평생든든_태블릿용.html` 파일 하나**를 태블릿에 넣고 브라우저로 열면 그대로 돌아갑니다. 인터넷이 끊겨 있어도 됩니다.

1. 파일을 태블릿의 **다운로드** 폴더에 저장합니다
2. **내 파일**(파일 관리자) 앱에서 그 파일을 누르고 **인터넷/Chrome 으로 열기**를 고릅니다
3. 브라우저 메뉴에서 **[홈 화면에 추가]** 를 해 두시면 다음부터는 아이콘만 누르면 됩니다

- 고객 자료는 **그 태블릿의 브라우저 안**에 쌓입니다. 인터넷으로 나가지 않습니다
- **브라우저 기록·저장공간을 지우면 자료도 함께 사라집니다.** 주 1회 ④ 탭의 **[전체 백업 파일 저장]** 을 꼭 눌러 주세요
- 엑셀은 **내려받기만** 됩니다 (매니저님 제출용). 작성한 엑셀을 올려서 읽어들이는 기능은 서버판에만 있습니다
- 내려받는 파일 이름은 `Kyobo-Ledger-20260812.xlsx` 처럼 영문입니다. 일부 브라우저가 한글 이름을 통째로 버려 확장자까지 사라지는 것을 막기 위해서입니다. 저장한 뒤 한글로 바꾸셔도 됩니다

파일을 다시 만들려면 (항목이나 판정 규칙을 고친 뒤):

```bash
npm run build:tablet
```

## PC에서 쓰기 — 더블클릭

| 쓰시는 컴퓨터 | 더블클릭할 파일 |
| --- | --- |
| 윈도우 | **`시작.bat`** |
| 맥 | **`시작(맥).command`** (처음에는 마우스 오른쪽 버튼 → 열기) |

브라우저가 저절로 열립니다. 다 쓰신 뒤에는 **검은 창을 닫으면** 프로그램이 꺼집니다
(창을 닫아도 저장하신 고객 자료는 그대로 남습니다).

- **처음 한 번만** Node.js 설치가 필요합니다. 설치가 안 되어 있으면 `시작` 파일이 알아서
  [nodejs.org](https://nodejs.org/ko) 를 열어 줍니다. **LTS** 를 받아 그대로 [다음]만 누르시면 됩니다.
- 처음 실행할 때 준비 작업에 2~3분 걸립니다. 그다음부터는 바로 켜집니다.
- "EADDRINUSE" 라고 나오면 이미 켜져 있는 것입니다. 브라우저에서 http://localhost:3000 을 바로 여세요.

### 명령으로 실행하기 (개발용)

```bash
npm install     # 처음 한 번만
npm start       # 서버 실행 → http://localhost:3000
```

| 명령 | 하는 일 |
| --- | --- |
| `npm start` | 서버 실행 (기본 3000번, `PORT=8080 npm start` 로 변경) |
| `npm run dev` | 파일을 고치면 자동으로 다시 시작 |
| `npm run template` | 서버를 켜지 않고 **엑셀 빈 서식** 파일만 만들기 |
| `npm run build:tablet` | 태블릿용 단일 HTML 파일 만들기 |
| `npm run build:web` | 위 파일에 앱 정보·오프라인 처리를 붙여 `docs/` 만들기 |

## 고객 자료는 어디에 쌓이나

프로그램 폴더 안 **`data/kyobo.db` 파일 하나**에 담깁니다. 인터넷으로 나가지 않고 그 컴퓨터에만 있습니다.

- 그 파일 하나만 복사하면 자료를 통째로 다른 PC로 옮길 수 있습니다
- 다른 폴더에 두시려면 `시작.bat` 을 메모장으로 열어 `set DB_PATH=...` 줄 앞의 `rem` 을 지우고 경로를 고치세요
  (맥은 `시작(맥).command` 의 `export DB_PATH=...` 줄에서 `#` 을 지우시면 됩니다)
- 프로그램 안의 **[전체 백업 파일 저장]** 과 **[누적 관리대장]** 으로도 언제든 빼낼 수 있습니다

> "서버"라고 되어 있지만 별도 서버 장비가 필요한 것이 아닙니다. 그 PC 안에서 도는 프로그램입니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| ① 고객 입력 | 인적사항 · 계약사항(가입건수 표) · 계약 DB분석(앞면/뒷면). 나이 · 만기일 자동 계산 |
| ② 진단 결과 | 숨은보험금 / 즉시조치 / 보완·제안 / 참고 항목을 급한 순서로. 안내 멘트와 근거 포함 |
| ③ 방문준비 · 상담메모 | 준비물 자동 체크(12), 상담내용 · 숨은보험금 발견 · 후속조치 표, 추가 점검사항(12), 상담 스크립트 |
| ④ 고객 누적 DB | 쌓인 방문기록을 고객별로. 불러오기 · 엑셀 · 삭제 · 백업 · 복원 |
| ⑤ 누적 통계 | 발견 예상액 누계, 등급 분포, 후속조치 기한, 월별 방문 추이 |

**입력 편의**

- 날짜는 `20030514` 처럼 숫자만 넣으셔도 `2003-05-14` 로 정리됩니다. 📅 단추로 달력에서 고를 수도 있습니다.
- 금액은 자리 쉼표가 자동으로 붙습니다.
- 가입연령 · 현재연령은 회사 기준(6개월 미만은 버리고, 6개월 이상이면 한 살 올림)으로 계산합니다.
- 납입 만료일 · 보험 만기일은 계약 표의 가입일과 기간(`20년`, `종신`, `80세`, `전기납` 등)에서 **줄마다** 자동으로 나옵니다.
  직접 넣으신 값은 덮어쓰지 않습니다.
- 계약 · 사고보험금 · 펀드 · 상담내용 · 숨은보험금 · 후속조치는 **줄을 늘리고 줄일 수 있는 표**입니다 (＋ 단추 / ✕ 단추).
- 입력 중인 내용은 이 컴퓨터에 자동 임시보관되어, 창을 닫았다 열어도 이어서 작업할 수 있습니다.

## 엑셀 서식

④ 탭의 **엑셀 서식** 칸에서 씁니다.

| 단추 | 하는 일 |
| --- | --- |
| 빈 서식 내려받기 | 입력용 `.xlsx`. 인쇄해서 손으로 적어 오셔도 됩니다 |
| 작성한 서식 올리기 | 채워 온 서식을 그대로 서버 DB에 등록 |
| 누적 관리대장 내려받기 | 전체 방문기록 목록 + 통계 시트 |
| 각 고객의 **[엑셀]** | 그 방문기록의 입력값 + **진단 결과 + 상담 스크립트**까지 담긴 파일 |

내려받은 서식은 시트가 나뉘어 있습니다 — `계약입력` / `계약사항` / `사고보험금` / `변액펀드` /
`상담메모` / `숨은보험금` / `후속조치` / `준비물체크` / `진단결과`.

서식 안에는 숨김 시트 `_meta` 가 들어 있어 **어느 칸이 어느 항목인지** 기록되어 있습니다.
그래서 내려받은 서식에 값만 채워 올리면 위치가 바뀌어도 정확히 읽어 들입니다.
(다른 데서 만든 엑셀은 읽을 수 없고, 그 경우 안내 문구가 나옵니다.)

## 항목을 늘리거나 고치려면

모든 항목은 **`shared/schema.js` 한 파일**에 정의되어 있습니다.
여기에 항목을 추가하면 **DB 컬럼 · 엑셀 서식 · CSV**가 자동으로 따라옵니다
(기존에 저장된 자료는 그대로 두고 컬럼만 추가됩니다).

- `SECTIONS` : 한 칸짜리 항목 (화면의 `id` 와 `k` 값을 같게 맞춰 주세요)
- `ROWSETS` : 여러 줄로 적는 표. 여기에 표를 하나 추가하면 화면 · 엑셀 시트 · 저장소가 함께 생깁니다
  (화면에는 `<div id="rs_표이름"></div>` 만 놓으면 됩니다)

웹 입력화면은 회사 양식 배치를 그대로 살리기 위해 `public/index.html` 에서 직접 그립니다.
입력칸 `id` 를 스키마의 `k` 값과 같게 만들어 주시면 되고,
빠뜨린 항목이 있으면 서버가 켜질 때 콘솔에 알려 줍니다.

```
shared/schema.js          항목 정의 (여기가 기준)
shared/calc.js            날짜 · 보험나이 · 기간 계산
shared/analysis.js        진단 엔진 (서버 · PC · 태블릿이 모두 같은 파일을 씁니다)
server/db.js              SQLite 저장소
server/excel.js           엑셀 서식 만들기 · 읽기
server/index.js           서버 · REST API
public/                   웹 화면 (서버판 · 태블릿용이 같은 화면을 씁니다)
standalone/local-api.js   태블릿용 저장 계층 (서버 자리를 브라우저가 대신)
standalone/xlsx-lite.js   브라우저에서 엑셀 파일을 직접 만드는 부분
scripts/build-standalone.js  위 조각들을 HTML 파일 하나로 묶기
평생든든_태블릿용.html      ← 태블릿에 넣을 파일 (묶어 놓은 결과물)
```

화면(`public/`)과 진단 규칙은 **서버판과 태블릿용이 같은 파일**을 씁니다.
저장하는 곳만 다릅니다 — 서버판은 SQLite, 태블릿용은 브라우저 저장소.

판정 규칙(예: 2006.02 이전 가입 여부, 수술특약 2종 50만원, 대장용종 주계약 200만·특약 100만)은
`shared/analysis.js` 안에 항목별로 나뉘어 있고, 각 항목에 안내 멘트와 근거가 함께 적혀 있습니다.
