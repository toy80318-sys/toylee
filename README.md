# 생애재무설계 플래너 (Financial Life Planner)

고객정보를 입력하면 생애 현금흐름을 연 단위로 시뮬레이션하고, 라이프사이클 차트·필요자금
상세분석·연도별 현금흐름표를 자동으로 만들어 주는 단일 HTML 파일 도구입니다.

* 파일: [`index.html`](index.html) — 외부 라이브러리 없이 브라우저에서 바로 열면 동작합니다.
* 웹사이트(아임웹 등)에 `<iframe>`으로 삽입할 수 있으며, 콘텐츠 높이를 부모 창에
  `postMessage({lifeplanHeight})`로 알려 줍니다.

## 기능

| 탭 | 내용 |
|---|---|
| ① 생애설계 차트 | 수입·지출 곡선(현재물가 기준), 누적자산 곡선, 경제적 정년·정년·은퇴 시점, 저축가능기간·최소책임기간·노후생활기간, 수입<지출 구간 음영 |
| ② 필요자금 상세분석 | 생애 현금흐름 요약, 자녀 교육·결혼자금, 노후자금, 사망보장(死), 중대질병 보장(病), 종합 진단 |
| ③ 연도별 현금흐름 | 현재 나이부터 기대여명까지 전 연도의 수입·지출·수지·금융자산 잔액과 주요 이벤트 |

부가 기능: 예시 입력 · 입력값 자동 저장(localStorage) · 고객 파일 저장/불러오기(.json) ·
차트 PNG 저장 · A4 인쇄 · 카카오톡 공유 · 상담 신청(Supabase 접수, 문자/이메일 대체 경로).

## 계산 모델

매년 `자산 = 전년도 자산 × (1 + 수익률) + (수입 − 지출)` 로 누적합니다.

* 수입 — 정년까지 근로소득(임금상승률 반영), 정년~완전은퇴는 현소득 대비 비율, 연금 개시 후 3층연금(국민·퇴직·개인)
* 지출 — 생활비(은퇴 후 비율 조정), 자녀 교육비(초·중·고·대), 자녀 결혼자금, 노후 의료·간병비, 대출 상환액
* 국민연금은 직접 입력이 없으면 `40% × (A값 + 본인평균소득)/2 × 가입연수/40` 로 추정합니다.
* 대출은 시작 자산에서 차감하지 않고 매년 상환액(상환액 미입력 시 이자)만 지출로 반영합니다.
  거주용 부동산이 상계하기 때문이며, 차감하면 시작부터 자산이 음수가 되어 고갈 시점을 오판합니다.
* 부족액이 있으면 이분탐색으로 **추가 필요 월저축**(은퇴 전 구간이 있을 때) 또는
  **추가 필요 일시금**(이미 은퇴한 경우)을 역산합니다.
* 차트는 비교를 위해 명목금액을 현재 물가 기준(실질)으로 환산해 표시합니다.

## 설정

`index.html` 상단 스크립트의 상수를 수정하세요.

```js
const ADVISOR  = { name:'담당 설계사', email:'...', phone:'...' };  // 상담 신청 수신처
const SUPABASE = { url:'...', key:'...', table:'lifeplan_consult_requests' };
```

Supabase 테이블은 `name, phone, preferred_time, topics, memo, planner_input,
planner_result, summary_text, source` 컬럼을 사용합니다. 공개키(publishable key)로
INSERT만 허용하도록 RLS 정책을 설정하는 것을 권장합니다.

## 주의

본 도구의 결과는 입력값과 명시된 가정에 근거한 추정치이며, 실제 수익률·물가·세제·제도
변화에 따라 달라질 수 있습니다. 국민연금 예상액은 국민연금공단 조회 금액을 직접 입력하면
더 정확합니다.
