# 계약자 관리 — 인수인계 메모

새 대화창에서 이어서 작업하실 때 이 문서를 먼저 읽으시면 됩니다.
(작업 브랜치 `claude/kyobo-customer-info-program-0fpvpm`, PR #1)

---

## 1. 이 프로그램이 하는 일

교보생명 FP가 **이미 계약하신 고객을 이어서 관리**하는 프로그램입니다.
설치 없이 **HTML 파일 하나**(`계약자관리.html`)로 태블릿에서 돌아갑니다.

컨셉은 **토끼 · 민트**(바탕은 미색). 짝이 되는 프로그램이 **평생든든 고객 정보파악**
(곰돌이 · 분홍, `평생든든_태블릿용.html`)입니다.

### 화면 — 탭 7개

| 탭 | 내용 |
| --- | --- |
| ① 고객정보 | 인적사항 · 보험나이/상령일 자동 · **📄 상품제안서 불러오기** · 가입설계 내역 |
| ② 보장설명 | **고객께 그대로 보여드리는 화면** — 특약별 쉬운 설명 · 증상별 보장금액 · 보장시작 · 감액 · 갱신 |
| ③ 환급금 | 경과년수 · 나이를 넣으면 **해약환급금 · 환급률 · 사망시 지급액**이 바로 (제안서 예시표에서 찾음) |
| ④ 청구내역 | 청구일 · 사고내용 · 지급액 · 처리상태 |
| ⑤ 상담메모 | 준비물 체크 · 상담내용 · 고객요청 · 후속조치 |
| ⑥ 고객터치 | **알림**이 뜨는 곳 + 연락 · 방문 기록 |
| ⑦ 누적통계 | 저장된 고객 · 월별 신규 추이 · 30일 알림 집계 · 바탕화면 아이콘 |

### 핵심 기능

**📄 상품제안서 불러오기 — 특약을 하나씩 고르지 않습니다**

1. FP가 상품제안서(가입설계서)를 사진·PDF로 대화창에 올립니다
2. 받은 **「설계 코드」**(JSON)를 프로그램의 [📄 제안서 불러오기]에 붙여넣습니다
3. 보험 · 특약 · 가입금액 · 보험료 · 납입/보험기간 · **해약환급금 예시표**가 한 번에 들어갑니다
4. 제안서에 적힌 **급부별 지급기준**이 그 보험의 약관 자료로 저장되어
   ② 보장설명 · 알림 · 엑셀에 그대로 쓰입니다 (다음 고객이 같은 상품이면 그대로 재사용)

설계 코드의 생김새는 `newcust/importer.js` 맨 위 주석에 있고,
실제 제안서를 옮긴 견본이 `newcust/sample-plan.json` 입니다.
화면의 **[예시 코드 넣어보기]** 를 누르면 바로 시험해 보실 수 있습니다.

**보장설명 (② 탭)** — 특약마다 카드 한 장

- 고객께 그대로 읽어 드릴 **쉬운 한 줄 설명**
- **증상별 보장금액** — 급부명 · 지급사유 · 얼마 (감액 중이면 감액된 금액과 전액을 같이)
- **보장 시작** — 면책기간이 끝나 보장이 시작되는 날
- **감액기간** — 언제까지 몇 %만 나오는지, 언제부터 전액인지
- **갱신** — 몇 년마다 · 다음 갱신일과 그때 나이 · 몇 세까지 갱신되는지
- **보장한도** · 청구할 때 챙길 것
- [표로 보기] 로 한눈에 · [인쇄 · PDF로 저장] 로 고객 전달용

**환급금 (③ 탭)** — 계산하지 않고 **제안서 표에서 찾습니다**

- 경과년수 **또는** 나이를 넣으면 → 낸 보험료 · 해약환급금 · 환급률 · 사망시 지급액
- 표에 없는 시점은 앞뒤 줄 사이를 이어 셈하고 **「사이값(참고)」** 이라고 밝힘
- 빠른 이동 : **지금 해지하면 · 납입 끝나면 · 낸 돈만큼 되는 때 · 표의 마지막**
- 낸 보험료와의 차액, 손익분기 시점을 함께 알려 줌
  (끝까지 100%가 안 되는 상품이면 **저축이 아니라 보장**이라는 점을 짚어 줍니다)

> **왜 계산하지 않나요** — 해약환급금은 「예정해약환급금 · 공시이율 적립액 · 최저보증액 중 큰 값」에서
> 보증비용을 빼고, 저해약환급금형이면 납입기간 중 **해지지급률(50%)** 까지 곱하는 구조입니다.
> 공시이율도 매달 바뀝니다. 어림잡아 계산하면 회사 금액과 어긋나 **잘못 안내**하게 되므로,
> 회사가 제안서에 찍어 드린 금액만 그대로 보여 줍니다.

**그 밖에**

- 보험명 드롭다운 → 고르면 그 상품의 약관 지급기준으로 계산 (손입력도 그대로 가능)
- **알림** — 생일 · 기념일 · 상령일 · **특약별 보장 개시일** · 감액 종료일 ·
  **갱신형 특약 갱신일** · 청약철회 15일 · 품질보증해지 3개월 · 계약 해당일 ·
  납입 만료일 · 보장 만기일 · 후속조치 기한
- 고객별 엑셀 11시트(보장설명 · 환급금요약 포함) · 누적 관리대장 · CSV · 전체 백업/복원

## 3. 약관 자료가 만들어진 방법

### 지금 들어 있는 것 — 상품 9건 · 특약 671건 (지급률까지 540건)

| 상품 | 특약 | 지급률까지 |
| --- | ---: | ---: |
| 교보마이플랜건강보험 (무배당) | 257 | 213 |
| 교보평생건강보험 PLUS (무배당) | 118 | 105 |
| 교보실속건강종신보험 [2409] (무배당, 보증비용부과형) | 114 | 100 |
| 교보더안심치매 · 간병보험 (무배당) | 69 | 50 |
| 교보 K-밸류업종신보험 (무배당) | 61 | 46 |
| 교보 K-실속종신보험 (무배당) | 27 | 20 |
| 교보경영인정기보험 [2501] (무배당) | 10 | — |
| 미리 보는 내 연금 (무)교보변액연금보험Ⅱ | 8 | 4 |
| 교보 모두지킴종신보험 (무배당) | 7 | 2 |

- **특약 이름**은 약관 **목차**에 적힌 그대로입니다
- **지급률**은 특약별 **(별표 1) 보험금 지급기준표**의 금액을
  `금액 ÷ 기준가입금액(보통 1,000만원)` 으로 환산했습니다
- **면책기간**은 그 특약 본문의 「보장개시일」 정의에서 (암 90일 · 치매 1년 등)
- **감액 · 보장한도**도 약관 표현 그대로

### 원본 약관 PDF

용량이 커서 **`main` 브랜치 저장소 맨 위**에 조각내어 있습니다 (약 200MB).
조각끼리 겹치는 쪽이 있어 읽을 때 자동으로 걸러냅니다.

### 다시 뽑는 방법

자동 추출 스크립트는 대화 작업용 임시 폴더에 있었고 저장소에는 없습니다.
새로 약관을 넣어야 하면 아래 순서로 다시 만들면 됩니다.

1. `origin/main` 에서 PDF 를 꺼낸다 (`git archive origin/main | tar -x -C <폴더>`)
2. `pypdf` 로 쪽별 텍스트를 뽑아 JSON 으로 저장 (겹치는 쪽은 md5 로 걸러냄)
3. 목차에서 `(무)…특약` 이름을 뽑아 **특약 목록**을 만든다
4. 본문에서 `무배당 …특약` 표지 쪽을 찾아 특약별 구간을 나눈다
5. 구간 안의 `( 별표 1 ) 보험금 지급기준표` 쪽을 파싱해
   `급부명 / 지급사유 / 지급금액` 을 뽑는다 (이어지는 다음 쪽도 함께)
6. 목차 이름 ← 표지 이름을 **이름이 같은 것 → 표지가 목차에 포함되는 것** 순서로만 잇는다
   (느슨하게 이으면 「암진단특약」에 「고액치료비암진단특약」 값이 붙습니다 — 실제로 났던 사고)
7. `newcust/products-gen.js` 로 출력

> `pypdf` 는 `pip install pypdf` 로 넣고, `_cffi_backend` 오류가 나면
> `pip install -U --force-reinstall cffi` 를 먼저 하세요.

## 4. 알아 두실 점

- **로그인 · 권한 기능이 없습니다.** 개인 기기 사용을 전제로 했습니다
- 자료는 **그 기기 브라우저 안**(localStorage)에 쌓입니다
  - 키 : `kyobo_newcust_v1` (고객) · `..._draft_v1` (임시) ·
    `..._dict_v1` (특약 사전) · `..._prod_v1` (보험 · 약관)
  - 파일 이름 · 위치가 바뀌면 자료가 안 보일 수 있음 → 백업 안내가 화면에 있음
- 화면 **[📕 보험 · 약관 고치기]** 에서 고친 값은 **언제나 파일 값보다 우선**하고
  그 기기에 저장됩니다
- 보장 · 지급보험금 자동 계산은 **참고용**입니다 (화면 하단에 고지)

### 알려진 자잘한 것

- 목차 이름과 본문 표지 이름이 다른 특약 몇 건(예: 목차 `(무)암진단특약(갱신형)Ⅱ`,
  본문 `New암진단특약(갱신형)Ⅱ`)은 안전하게 **표준값**으로 계산합니다
- 자동으로 뽑은 급부명에 PDF 줄바꿈 흔적이 남은 것이 드물게 있습니다
  (예: `액재진단암생활자금`) — 화면에서 고칠 수 있습니다

## 5. 제안서를 「설계 코드」로 옮기는 방법 (사람이 대화창에서 하는 일)

FP가 상품제안서 사진을 올리면, 아래 항목을 찾아 `newcust/sample-plan.json` 모양으로 만들어 주면 됩니다.

**찾을 곳 — 교보생명 상품제안서 (37쪽 기준)**

| 무엇 | 어디에 |
| --- | --- |
| 상품명 · 피보험자 · 가입금액 · 납입기간 · 월보험료 | 표지 (1쪽) |
| 주계약 급부별 보장금액 · 지급사유 · 보험료 | 「보장 내용 — 주계약」 (5쪽 근처) |
| 특약별 급부 · 보장금액 · 지급사유 · 보험료 | 「보장 내용 — 1. ○○특약」 (6쪽 이후) |
| **해약환급금 예시표** | 「주계약 사망시 지급액(계약자적립액) 및 해약환급금 예시표」 (10 ~ 11쪽) |
| 면책기간 · 감액 | 급부 표 아래 ※ 주석 (「보장개시일」 · 「1년 미만 … 50% 감액」) |

**주의할 점**

- **환급금표는 「주계약＋특약」 쪽 열**을 씁니다 (제안서에 「주계약만」 열이 따로 있습니다)
- 「경과」는 `3개월` · `1년` · `47년` 처럼 제안서 글자 그대로 넣습니다
- **납입이 끝나는 줄**에 `"구분": "납입완료"`, 만기 줄에 `"구분": "만기"` 를 넣으면
  화면의 빠른 이동 단추와 엑셀 요약이 그 줄을 짚습니다
- `해약환급금: 0` 은 **0 그대로** 넣습니다 (빈칸으로 두면 안 됩니다 — 초기에 환급금이 없다는 중요한 사실입니다)
- 갱신형 특약은 `"보험기간": "7년만기"` 가 곧 갱신주기입니다.
  몇 세까지 갱신되는지는 제안서에서 찾아 `"갱신종료나이"` 에 넣어 주세요 (없으면 비워도 됩니다)
- 금액은 **원 단위**(급부·보험료·환급금), 가입금액만 **만원 단위**입니다

**스캔 PDF 다루기**

스캔본은 텍스트가 없어 이미지로 봐야 합니다. 뒤집혀 들어오는 경우가 많습니다.

```bash
apt-get install -y poppler-utils          # pdftoppm — 페이지를 그림으로
python3 -c "
from pypdf import PdfReader, PdfWriter
r=PdfReader('in.pdf'); w=PdfWriter()
for p in r.pages: p.rotate(180); w.add_page(p)
w.write(open('out.pdf','wb'))"
```

앞뒤로 나눠 스캔하면 한 파일은 홀수쪽, 다른 파일은 **짝수쪽 역순**으로 들어옵니다
(실제로 그랬습니다 — B파일 n번째 = 물리 40−2n쪽).
