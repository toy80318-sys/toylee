# 고객 맞춤 보장분석 안내문 만들기

고객정보를 입력하고 **상품제안서(스캔본 가능)** 를 올리면,
저장소에 있는 **약관 PDF** 를 자동으로 찾아 읽어서
고객이 이해하기 쉬운 **A4 안내문**을 만들어 주는 프로그램입니다.

## 계약사항 표 안에 메모가 들어갑니다

제안서의 계약사항 표를 그대로 옮기고, 오른쪽 칸에 **쉬운 설명 · 보장 대상 코드 · 지급 기준 · 주의 태그**를
자동으로 채워 넣습니다. 표만 필요하면 `계약사항 표만 인쇄` 옵션(명령줄은 `--table-only`)을 쓰면
A4 3~4장으로 끝납니다.

| 구분 | 보장(특약) | 가입금액 | 납입/보험기간 | 보험료 | 쉬운 설명 · 보장 대상 코드 · 지급 기준 |
|---|---|---|---|---|---|
| 진단 | 뇌혈관질환진단특약L<br><sub>약관: 무배당 뇌혈관질환진단특약L</sub> | 1,000만원 | 20년납/100세만기 | 20,600원 | ‘뇌혈관질환’으로 진단이 확정되면 진단보험금을 한 번에 드립니다.<br>**대상 코드** `I60~I69` (총 10개 항목)<br>**지급** 진단 확정 시 1,000만원 · 최초 1회 한<br>`1년 내 50%만 지급` `일부 질병 제외` `장해 50% 이상 시 납입면제` |
| 입원 | 뇌혈관질환상급종합병원입원특약L | 1,000만원 | 20년납/100세만기 | 590원 | ‘뇌혈관질환’ 때문에 입원하면 입원한 날짜만큼 보험금을 드립니다.<br>**대상 코드** `I60~I69`<br>**지급** 입원 1일당 정해진 보험금 지급 · 1회 입원 120일 한도 |

- **구분**은 특약 유형(진단·입원·수술·치료·재해·보험료 면제)으로 자동 분류됩니다.
- **갱신 주기**는 제안서에 적힌 값(예: 5년갱신)을 우선해서 태그로 넣습니다.
- 특약명은 제안서에 적힌 이름을 그대로 쓰고, 그 아래에 근거가 된 **약관상 특약명**을 작게 병기합니다.
  다른 상품 약관을 근거로 삼은 경우(예: 간편심사형 약관이 없어 일반형으로 대조) 표에 함께 표시합니다.

안내문에는 특약마다 다음 내용이 자동으로 채워집니다.

| 항목 | 내용 | 어디서 가져오나 |
|---|---|---|
| 한 줄 요약 | "'뇌혈관질환'으로 진단이 확정되면 진단보험금을 한 번에 드립니다" | 보험금의 지급사유 조문 |
| 어떤 병이 대상인가 | **I60~I69** 등 질병분류코드 + 병명 + 쉬운 설명 | (별표) ○○ 분류표 |
| 어떤 상황에서 나오는가 | 지급사유 각 호 | 보험금의 지급사유 조문 |
| 꼭 확인할 점 | 90일 면책, 1년 미만 50% 감액, 최초 1회 한, 1회 입원당 120일, CDR 3점 이상, 갱신 시 보험료 인상 … | 정의·세부규정·보장개시·갱신 조문 |
| 안 나오는 경우 | 고의 사고 등 | 보험금을 지급하지 않는 사유 조문 |
| 청구 서류 | 진단서(질병분류코드 기재) 등 | 보험금 등의 청구 조문 |
| 근거 | `제4조(보험금의 지급사유)`, `교보평생건강보험 PLUS 1.pdf p.41~122` | 색인 |

> 안내문은 **참고 자료**입니다. 실제 보장 여부는 약관 원문과 회사 심사 기준에 따릅니다.
> 이 문구는 안내문 마지막 장에도 자동으로 인쇄됩니다.

## 1. 처음 한 번만 준비하기

### (1) 파이썬 설치
- Windows: [python.org](https://www.python.org/downloads/) 에서 설치
  (설치 화면에서 **Add Python to PATH** 를 꼭 체크)
- macOS: 이미 설치되어 있거나 `brew install python`

### (2) 필요한 프로그램 설치
저장소 폴더에서 터미널(명령 프롬프트)을 열고:

```bash
cd insurance_note
pip install -r requirements.txt
```

### (3) 스캔본을 읽으려면 (선택) — OCR 설치
제안서가 **스캔 이미지**면 글자 인식(OCR)이 필요합니다. 텍스트 PDF만 쓰면 건너뛰어도 됩니다.

- Windows: <https://github.com/UB-Mannheim/tesseract/wiki> 에서 설치 (언어 선택에서 **Korean** 체크)
- macOS: `brew install tesseract tesseract-lang`
- Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-kor`

### (3-1) 약관을 다른 폴더에 두고 싶다면 (권장)

약관 PDF 를 프로그램 폴더 밖(내 PC 안)에 두면, 프로그램만 주고받아도
약관이 함께 따라다니지 않습니다. `약관폴더.txt` 첫 줄에 폴더를 적어 주세요.

```
C:\진이폴더\보험\약관
```

이미 색인(`data/terms_index.sqlite`)이 만들어져 있으면 약관을 옮겨도 프로그램은 그대로 동작합니다.
약관을 새로 넣거나 바꿨을 때만 색인을 다시 만들면 됩니다.

### (4) 약관 색인 만들기 (1~2분, 한 번만)

```bash
python3 build_index.py
```

저장소 최상위의 약관 PDF를 모두 읽어 `data/terms_index.sqlite` 를 만듭니다.
약관 PDF를 새로 넣거나 바꾸면 이 명령을 다시 실행하면 됩니다.

```
완료: 상품 7개 / 파일 38개 / 약관구간 644개 / 조문 11,984개 / 분류표 687개 / 질병코드 14,365개
```

## 2. 바탕화면 아이콘으로 실행하기 (가장 쉬움)

> 위 (2)(4) 단계를 몰라도 됩니다. 아이콘이 알아서 설치하고 색인까지 만듭니다.

### 윈도우
1. `insurance_note` 폴더에서 **`바탕화면 아이콘 만들기.bat`** 를 더블클릭
2. 바탕화면에 생긴 **[보장안내문 만들기]** 아이콘을 더블클릭

### 맥 · 리눅스
```bash
python3 tools/make_shortcut.py     # 바탕화면에 아이콘 생성
```
(또는 `실행하기.command` 를 바탕화면으로 끌어다 놓아도 됩니다.)

아이콘을 누르면 검은 창이 하나 뜨고, **브라우저가 자동으로 열립니다.**

- 처음 한 번은 필요한 프로그램 설치 + 약관 색인 만들기로 **2~4분** 걸립니다(진행 상황이 창에 표시됩니다).
- 두 번째부터는 몇 초 만에 열립니다.
- **끝낼 때는 검은 창을 닫으면** 됩니다.

| 파일 | 역할 |
|---|---|
| `실행하기.bat` / `실행하기.command` | 더블클릭하면 프로그램이 켜집니다 |
| `바탕화면 아이콘 만들기.bat` | 바탕화면에 아이콘(바로가기)을 만듭니다 |
| `assets/보장안내문.ico` `.png` | 아이콘 그림 |

## 3. 사용하기 (웹 화면)

```bash
python3 app.py
```

브라우저에서 <http://127.0.0.1:5000> 접속 → 3단계로 끝납니다.

1. **고객정보 입력** — 성함·생년월일·연락처·상담 메모
2. **상품제안서 올리기** — PDF 또는 스캔 이미지.
   `파일 고르기 / 더 추가하기` 를 **여러 번 눌러 한 장씩 계속 더할 수 있고**,
   한 번에 여러 장을 골라도 되고, 칸 위로 **끌어다 놓아도** 됩니다.
   고른 파일은 목록으로 보이고 `빼기` 로 하나씩 뺄 수 있습니다.
   여러 파일을 합쳐서 읽고, 페이지가 겹쳐 같은 특약이 두 번 나오면 한 번만 담습니다.
   한 장이 손상됐거나 읽을 수 없는 형식(예: `.hwp`)이면 **그 장만 건너뛰고** 이유를 알려 줍니다.
   (파일 대신 내용 붙여넣기도 가능)

   > 한 번에 올릴 수 있는 총 용량은 500MB 입니다. 더 필요하면
   > `NOTE_MAX_UPLOAD_MB` 환경변수로 늘릴 수 있습니다.
3. **내용 확인 → 인쇄** — 자동으로 찾은 특약을 확인하고
   `안내문 미리보기 / 인쇄` → 브라우저 인쇄창에서 **A4 · 배율 100% · 배경 그래픽 켜기**

인쇄창에서 `대상: PDF로 저장` 을 고르면 그대로 PDF 파일이 됩니다.

### 검토 화면에서 할 수 있는 것
- 특약 이름·가입금액·보험료 수정
- **일치도(%)** 확인 — 스캔 글자가 잘못 읽혔으면 검색창에서 올바른 특약을 골라 교체
- 특약 직접 추가 / 삭제
- 특약마다 설계사 메모 입력(안내문에 함께 인쇄)
- 근거 조문 표시 여부, 계약사항 표만 인쇄, 질병분류표 전체 인쇄 여부 선택

## 4. 사용하기 (명령줄 한 방)

```bash
python3 make_note.py --proposal 제안서.pdf --name 홍길동 \
    --planner 이설계 --planner-phone 010-1234-5678 \
    --out 홍길동_보장안내문.html
```

제안서가 여러 장이면 `--proposal` 을 여러 번 씁니다.

```bash
python3 make_note.py --proposal 1장.pdf --proposal 2장.pdf --name 홍길동 --out 안내문.html
```

특약을 직접 지정할 수도 있습니다.

표(메모 포함)만 뽑으려면 `--table-only` 를 붙입니다.

```bash
python3 make_note.py --proposal 제안서.pdf --name 홍길동 --table-only --out 표.html
```

```bash
python3 make_note.py --rider "무배당 암진단특약H" --rider "(무)교보뇌혈관질환진단특약(갱신형)Ⅱ" \
    --name 홍길동 --out 안내문.html
```

만들어진 HTML은 **스타일이 안에 들어 있어** 그대로 고객에게 보내거나 열어서 인쇄할 수 있습니다.

## 5. 옵시디언(Obsidian)으로 약관 노트 만들기

약관 색인에 들어 있는 **특약 643건을 옵시디언 노트로** 한 번에 뽑아냅니다.
특약 · 상품 · 질병분류코드가 `[[링크]]` 로 이어져, `I60~I69` 노트를 열면
그 코드를 보장하는 특약이 백링크로 모두 보입니다.

### 준비
`옵시디언_폴더.txt` 를 메모장으로 열어 **첫 줄에 보관함(vault) 경로**를 적습니다.

```
C:\진이폴더\보험\옵시디언
```

### 실행
**`옵시디언으로 내보내기.bat`** 를 더블클릭하면 끝입니다. (명령줄은 아래)

```bash
python3 tools/obsidian_export.py                       # 전체
python3 tools/obsidian_export.py --product 마이플랜      # 한 상품만
python3 tools/obsidian_export.py --vault "D:\보관함"     # 폴더 직접 지정
```

### 만들어지는 것

```
<보관함>/보험약관/
├── 00 약관 색인.md      상품별 특약 수 · 전체 목차
├── 특약/               특약 643개 (한 장에 보장 코드·지급사유·주의사항·근거)
├── 상품/               상품 7개 (그 상품의 특약 목록)
└── 질병분류/            질병코드 287개 (I60~I69 등)
```

- 특약 노트에는 **보장 대상 질병표(코드·쉬운 설명)**, 언제 보험금이 나오는지,
  꼭 확인할 점(면책·감액·갱신), 안 나오는 경우, 청구 서류, 근거 조문이 들어갑니다.
- 이름이 같은 특약이 여러 상품에 있으면 `무배당 암진단특약L (마이플랜)` 처럼 상품명을 붙여 구분합니다.
- 노트 맨 아래 **`## 내 메모`** 칸에 적은 내용은 **다시 내보내도 지워지지 않습니다.**
  고객 상담 기록이나 판매 포인트를 여기에 쌓아 두세요.

### 고객 보장분석도 노트로 (테블릿 상담용)

검토 화면의 **`옵시디언에 저장`** 버튼을 누르면 그 고객의 보장분석이
`<보관함>/보험약관/고객/홍길동 2026-08-24.md` 로 저장됩니다.

- 계약사항 표가 그대로 들어가고, 각 특약은 **약관 노트로 링크**됩니다
- 상담 중 테블릿에서 특약 이름을 누르면 보장 코드·면책·감액 조건이 바로 열립니다

> **주의** — 고객 노트에는 고객 성함·생년월일·연락처가 들어갑니다.
> 보관함을 클라우드로 동기화하신다면 그 회사 서버에 올라갑니다.
> 고객 정보를 올리고 싶지 않으면 `고객` 폴더를 동기화에서 제외하세요.

### 테블릿에서 쓰기

프로그램(파이썬)은 테블릿에서 돌지 않습니다. **PC 에서 노트를 만들고, 테블릿은 옵시디언 앱으로 보는** 구조입니다.

```
PC: 약관 → 노트 만들기 → 보관함 폴더에 저장
              ↓ 동기화
테블릿: 옵시디언 앱으로 조회·메모
```

동기화 방법은 아이패드면 iCloud, 안드로이드면 구글드라이브·Syncthing,
양쪽 다 쓰시면 유료 Obsidian Sync 가 가장 간단합니다.

상담 중에는 **`01 질병코드 찾아보기`** 노트가 편합니다.
고객이 말한 병명·코드를 찾아 누르면, 그 코드를 보장하는 특약이 전부 보입니다.

## 6. 태블릿에서 쓰기 (PC 없이)

프로그램(파이썬)은 태블릿에서 돌지 않습니다. 대신 **약관 분석 결과를 담은 화면 파일 하나**를
만들어 태블릿으로 옮기면, 인터넷 없이 브라우저에서 그대로 씁니다.

**`태블릿용 화면 만들기.bat`** 를 더블클릭하면 바탕화면에 `보장분석_도우미.html` (약 2MB)이 생깁니다.
이 파일 하나만 태블릿에 옮겨 크롬으로 열고 즐겨찾기에 넣으세요.

```bash
python3 tools/make_tablet_app.py            # 바탕화면에 저장
python3 tools/make_tablet_app.py --out 내파일.html
```

| 화면 | 하는 일 |
|---|---|
| 특약 찾기 | 특약 검색 → 보장 질병표·지급사유·면책·감액·청구서류 |
| 질병코드 | `I63`·`뇌경색` 입력 → 그 병을 보장하는 특약 전부 |
| 보장분석 | 고객정보 + 담은 특약 → 표 → 인쇄/PDF 저장, 옵시디언용 복사 |

제안서 표를 복사해 붙여넣으면 특약을 자동으로 담습니다(사진·PDF 읽기는 PC 전용).
담은 내용과 고객정보는 브라우저에 남아 새로고침해도 유지됩니다.

## 8. 쉬운 말 사전 고치기

`data/glossary.json` 을 메모장으로 열어 고치면 안내문 문구가 바로 바뀝니다.

- `질병용어` : 약관 병명 → 고객이 알아듣는 설명 (`"뇌경색증": "뇌혈관이 막혀 …"`)
- `코드군` : 코드 범위 → 뜻 (`"I60~I69": "뇌혈관질환 전체"`)
- `보험용어` : 진단확정·보장개시일·감액 등 용어 풀이
- `특약유형` : 진단형·입원형 등 기본 한 줄 설명

사전에 없는 병명은 `○○의 악성 신생물` → `○○에 생긴 암` 처럼 규칙으로 자동 설명합니다.

## 9. 자주 있는 상황

| 상황 | 해결 |
|---|---|
| "약관 색인이 없습니다" | `python3 build_index.py` 실행 |
| 스캔 제안서에서 특약을 못 찾음 | OCR 설치 확인 → 검토 화면에서 직접 추가/검색 |
| **사진(JPG·PNG)을 올렸더니 "OCR 프로그램이 없습니다"** | 사진에서 글자를 읽으려면 tesseract 설치가 필요합니다. [UB-Mannheim 설치본](https://github.com/UB-Mannheim/tesseract/wiki) 에서 설치할 때 **Additional language data → Korean** 을 선택하세요. 설치 후 프로그램을 껐다 켜면 자동 인식합니다(PATH 에 없어도 흔한 설치 경로를 찾아봅니다). 다른 곳에 설치했다면 `NOTE_TESSERACT` 에 `tesseract.exe` 전체 경로를 지정하세요 |
| OCR 없이 급할 때 | 제안서 표를 복사해 **'파일 대신 제안서 내용을 붙여넣기'** 칸에 붙여넣거나, 검토 화면에서 특약을 직접 추가 |
| 특약 이름이 비슷해 잘못 매칭됨 | 검토 화면의 일치도(%)를 보고 검색으로 교체 |
| 아이콘을 눌렀는데 검은 창만 뜨고 끝난다 | 창에 적힌 안내(파이썬 설치 등)를 확인하세요. 창이 바로 닫히면 `실행하기.bat` 를 직접 더블클릭해 메시지를 확인 |
| 브라우저가 자동으로 안 열린다 | `주소.txt` 파일에 적힌 주소를 주소창에 붙여넣기(보통 `http://127.0.0.1:5000`) |
| **"사이트에 연결할 수 없음 / 연결을 거부했습니다"** | 프로그램(검은 창)이 꺼진 상태입니다. 아이콘을 다시 실행한 뒤 브라우저에서 새로고침(F5). 5000번 자리가 다른 프로그램에 잡혀 있으면 자동으로 다른 번호를 쓰므로, 검은 창이나 `주소.txt` 의 주소를 확인하세요 |
| 큰 스캔본을 올리면 프로그램이 꺼진다 | 해상도를 자동으로 낮춰 읽고, 꺼져도 스스로 다시 시작합니다. 계속 꺼지면 `실행기록.txt` 의 마지막 줄을 확인하세요 |
| 안내문이 너무 길다 | `계약사항 표만 인쇄` 를 켜면 3~4장으로 끝납니다 |
| 간편심사(간편N355) 상품인데 일반형 약관으로 매칭됨 | 해당 상품 약관 PDF를 폴더에 넣고 `python3 build_index.py` 재실행 |
| 인쇄하면 색이 안 나온다 | 인쇄창에서 **배경 그래픽(Background graphics)** 켜기 |
