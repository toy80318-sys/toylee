# 고객 맞춤 보장분석 안내문 만들기

고객정보를 입력하고 **상품제안서(스캔본 가능)** 를 올리면,
저장소에 있는 **약관 PDF** 를 자동으로 찾아 읽어서
고객이 이해하기 쉬운 **A4 안내문**을 만들어 주는 프로그램입니다.

안내문에는 특약마다 다음 내용이 자동으로 채워집니다.

| 항목 | 내용 | 어디서 가져오나 |
|---|---|---|
| 한 줄 요약 | "'뇌혈관질환'으로 진단이 확정되면 진단보험금을 한 번에 드립니다" | 보험금의 지급사유 조문 |
| 어떤 병이 대상인가 | **I60~I69** 등 질병분류코드 + 병명 + 쉬운 설명 | (별표) ○○ 분류표 |
| 어떤 상황에서 나오는가 | 지급사유 각 호 | 보험금의 지급사유 조문 |
| 꼭 확인할 점 | 90일 면책, 1년 미만 50% 감액, 최초 1회 한, 1회 입원당 120일, CDR 3점 이상, 갱신 시 보험료 인상 … | 정의·세부규정·보장개시·갱신 조문 |
| 안 나오는 경우 | 고의 사고 등 | 보험금을 지급하지 않는 사유 조문 |
| 청구 서류 | 진단서(질병분류코드 기재) 등 | 보험금 등의 청구 조문 |
| 근거 | `제4조(보험금의 지급사유)`, `교보평생건강보험 PLUS 1.pdf p.41~122` | 색인 |

> 안내문은 **참고 자료**입니다. 실제 보장 여부는 약관 원문과 회사 심사 기준에 따릅니다.
> 이 문구는 안내문 마지막 장에도 자동으로 인쇄됩니다.

---

## 1. 처음 한 번만 준비하기

### (1) 파이썬 설치
- Windows: [python.org](https://www.python.org/downloads/) 에서 설치
  (설치 화면에서 **Add Python to PATH** 를 꼭 체크)
- macOS: 이미 설치되어 있거나 `brew install python`

### (2) 필요한 프로그램 설치
저장소 폴더에서 터미널(명령 프롬프트)을 열고:

```bash
cd insurance_note
pip install -r requirements.txt
```

### (3) 스캔본을 읽으려면 (선택) — OCR 설치
제안서가 **스캔 이미지**면 글자 인식(OCR)이 필요합니다. 텍스트 PDF만 쓰면 건너뛰어도 됩니다.

- Windows: <https://github.com/UB-Mannheim/tesseract/wiki> 에서 설치 (언어 선택에서 **Korean** 체크)
- macOS: `brew install tesseract tesseract-lang`
- Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-kor`

### (4) 약관 색인 만들기 (1~2분, 한 번만)

```bash
python3 build_index.py
```

저장소 최상위의 약관 PDF를 모두 읽어 `data/terms_index.sqlite` 를 만듭니다.
약관 PDF를 새로 넣거나 바꾸면 이 명령을 다시 실행하면 됩니다.

```
완료: 상품 7개 / 파일 38개 / 약관구간 644개 / 조문 11,984개 / 분류표 687개 / 질병코드 14,365개
```

## 2. 사용하기 (웹 화면)

```bash
python3 app.py
```

브라우저에서 <http://127.0.0.1:5000> 접속 → 3단계로 끝납니다.

1. **고객정보 입력** — 성함·생년월일·연락처·상담 메모
2. **상품제안서 올리기** — PDF 또는 스캔 이미지(파일 대신 내용 붙여넣기도 가능)
3. **내용 확인 → 인쇄** — 자동으로 찾은 특약을 확인하고
   `안내문 미리보기 / 인쇄` → 브라우저 인쇄창에서 **A4 · 배율 100% · 배경 그래픽 켜기**

인쇄창에서 `대상: PDF로 저장` 을 고르면 그대로 PDF 파일이 됩니다.

### 검토 화면에서 할 수 있는 것
- 특약 이름·가입금액·보험료 수정
- **일치도(%)** 확인 — 스캔 글자가 잘못 읽혔으면 검색창에서 올바른 특약을 골라 교체
- 특약 직접 추가 / 삭제
- 특약마다 설계사 메모 입력(안내문에 함께 인쇄)
- 근거 조문 표시 여부, 질병분류표 전체 인쇄 여부 선택

## 3. 사용하기 (명령줄 한 방)

```bash
python3 make_note.py --proposal 제안서.pdf --name 홍길동 \
    --planner 이설계 --planner-phone 010-1234-5678 \
    --out 홍길동_보장안내문.html
```

특약을 직접 지정할 수도 있습니다.

```bash
python3 make_note.py --rider "무배당 암진단특약H" --rider "(무)교보뇌혈관질환진단특약(갱신형)Ⅱ" \
    --name 홍길동 --out 안내문.html
```

만들어진 HTML은 **스타일이 안에 들어 있어** 그대로 고객에게 보내거나 열어서 인쇄할 수 있습니다.

## 4. 폴더 구성

```
insurance_note/
├── build_index.py      약관 PDF -> 색인 만들기(처음 한 번)
├── app.py              웹 화면 실행
├── make_note.py        명령줄에서 안내문 바로 만들기
├── noteapp/
│   ├── indexer.py      약관 PDF 읽기 · 특약 구간/조문/분류표 분해
│   ├── store.py        색인 조회 · 특약 이름 매칭
│   ├── proposal.py     제안서 읽기(텍스트 · OCR) · 특약 표 파싱
│   ├── explain.py      약관 문장 -> 고객용 쉬운 설명(규칙 엔진)
│   ├── report.py       안내문 데이터 조립
│   └── session.py      작업 저장/불러오기
├── templates/          화면 · 인쇄용 A4 서식
├── static/             화면 · 인쇄 스타일
├── data/glossary.json  쉬운 말 사전(자유롭게 수정 가능)
├── samples/            예시 제안서
└── tests/test_basic.py 동작 점검
```

## 5. 쉬운 말 사전 고치기

`data/glossary.json` 을 메모장으로 열어 고치면 안내문 문구가 바로 바뀝니다.

- `질병용어` : 약관 병명 → 고객이 알아듣는 설명 (`"뇌경색증": "뇌혈관이 막혀 …"`)
- `코드군` : 코드 범위 → 뜻 (`"I60~I69": "뇌혈관질환 전체"`)
- `보험용어` : 진단확정·보장개시일·감액 등 용어 풀이
- `특약유형` : 진단형·입원형 등 기본 한 줄 설명

사전에 없는 병명은 `○○의 악성 신생물` → `○○에 생긴 암` 처럼 규칙으로 자동 설명합니다.

## 6. 자주 있는 상황

| 상황 | 해결 |
|---|---|
| "약관 색인이 없습니다" | `python3 build_index.py` 실행 |
| 스캔 제안서에서 특약을 못 찾음 | OCR 설치 확인 → 검토 화면에서 직접 추가/검색 |
| 특약 이름이 비슷해 잘못 매칭됨 | 검토 화면의 일치도(%)를 보고 검색으로 교체 |
| 안내문이 너무 길다 | `질병분류표 전체 싣기` 를 끄면 코드 범위 + 대표 항목만 인쇄 |
| 인쇄하면 색이 안 나온다 | 인쇄창에서 **배경 그래픽(Background graphics)** 켜기 |

## 7. 동작 점검

```bash
python3 tests/test_basic.py
```
