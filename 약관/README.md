## 넣어 주시면 제가 하는 일

1. 약관의 **(별표 1) 보험금 지급기준표**와 **보험약관 요약서**를 읽어
   특약별 **보장영역 · 지급률 · 면책기간 · 감액기간 · 보장한도**를 뽑습니다.
2. `newcust/products.js` 의 상품 목록에 채워 넣습니다.
3. 프로그램 ②의 **보험명 드롭다운**에 그 상품이 뜨고, 고르시면
   **그 약관의 지급기준으로 보험금이 자동 계산**됩니다.
