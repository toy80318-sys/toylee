특약 이름은 **약관 목차에 적힌 그대로**이고,
「지급률까지」는 그중 **(별표 1) 보험금 지급기준표**의 금액을 옮긴 특약 수입니다.
나머지 특약은 이름만 들어 있고 **특약 사전의 표준값**으로 계산합니다.

약관이 「특약보험가입금액 1,000만원」을 기준으로 금액을 적어 두므로
`그 금액 ÷ 기준금액` 을 지급률로 넣었습니다. (예 200만원 → 20%)

## 원본 약관 파일은 어디에

용량이 커서 `main` 브랜치의 저장소 맨 위에 조각내어 두었습니다.
조각끼리 겹치는 쪽은 자동으로 한 번만 읽습니다.
읽어서 `newcust/products-gen.js` 를 만든 뒤에는 프로그램이 그 파일만 쓰므로,
원본 PDF는 보관용입니다.

## 새 약관을 넣으시려면

1. 이 폴더(또는 저장소 아무 곳)에 PDF를 올려 주세요
2. **한 파일이 25MB를 넘으면 GitHub 웹 업로드가 막힙니다.** 크롬으로 PDF를 열고
   `Ctrl+P` → 대상 **`PDF로 저장`** → 페이지 **맞춤**(예 `1-400`)으로 나눠 올리시면 됩니다
3. 올리시고 말씀해 주시면 읽어서 상품 목록에 넣겠습니다
